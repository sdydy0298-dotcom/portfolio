# 서동연 · Portfolio

Version **1.0.0** · 2026-10-27

## 2026.10.27 수정

- 프로젝트 제목은 `Project`로 정리하고 반복 소개 문구를 제거했습니다.
- 서비스 사진과 토폴로지는 원본 비율로 표시합니다. PC·태블릿·모바일에서 설명이 가로로 넘치지 않도록 레이아웃을 수정했습니다.
- 자격증은 이력서 검증 기록의 취득월을 복원해 최신순으로 한 줄씩 표시합니다. Spring 백엔드 개발자 양성과정(코리아 IT 아카데미, 2023.02–2023.05)을 복원했습니다.
- 프로젝트 상세는 구축·문제 해결 / 토폴로지 / 서비스 화면의 세 탭으로 구성합니다.
- Enterprise Network: 최신 전체 토폴로지와 IDC·본사·지사·FTTH 상세 토폴로지 4장.
- ALEPH Arena: 한국·일본 전체 토폴로지, 망 분리·OSPF/정적 경로·UDP Tunnel 연동 설명. 직접 맡은 한국 IDC 작업과 팀 전체 결과, 일본 IDC의 미완료 통합 시험을 구분했습니다.

첨부된 토폴로지 원본을 사용했으며 팀 보고서 전체와 팀원 개인 정보는 공개 파일에 넣지 않았습니다. 게임 프로젝트의 추가 내용은 제공된 수행 결과보고서의 네트워크·서버 구성과 검증 결과를 바탕으로 정리했습니다.

## 2026.10.26 개편

기존 긴 단일 페이지를 소개·경력과 대표 프로젝트의 두 페이지로 정리했습니다. 프로필 사진을 추가하고 반복되는 소개·강점·기술 설명을 줄였습니다. 프로젝트는 역할·문제 해결·확인 결과를 먼저 보여주며, 상세 기록과 사진은 버튼으로 확인합니다.

- `/#profile`: 프로필·경력·기술·학력·자격증
- `/#projects`: ALEPH Arena, Enterprise Network
- ALEPH Arena 서비스 사진 5장·토폴로지 1장, Enterprise Network 서비스 사진 5장·토폴로지 5장
- PC·모바일 반응형, 키보드 조작·ESC 닫기·포커스 복귀, 두 페이지 인쇄 스타일

## 실행

Node.js 24.x. 외부 런타임 의존성 없이 동작합니다.

```bash
npm run check
npm run build
```

## 콘텐츠 관리

- `index.html`: 사진·소개·경력·기술·학력·자격증
- `app.js`의 `compact`: 프로젝트 요약과 짧은 구축·문제 해결 기록
- `content.json`: 공개 프로젝트 ID·제목·서비스 사진·토폴로지 목록
- `assets/`: 프로필·프로젝트 이미지
- `styles.css`: 두 페이지 레이아웃과 반응형·인쇄 스타일

기존 Supabase 상세 원문은 보존합니다. 빌드 시 기존 공개 레코드의 제목을 조회한 뒤 브라우저에는 ID·제목·서비스 사진·토폴로지 목록만 출력합니다. 상세 원문·내부 주소 등은 정적 JSON에 포함하지 않습니다. 브라우저에 DB 키를 전달하지 않습니다.

**요약 전용 content.json을 DB 상세 원문 전체에 덮어쓰지 마세요.** `sync:sql` 스크립트도 요약 데이터의 전체 덮어쓰기를 차단합니다. 원문 편집은 기존 Supabase 레코드에서 수행합니다.

GitHub `main`의 변경을 기존 Vercel 프로젝트가 배포합니다. 기존 환경 변수 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`와 RLS 정책을 유지합니다.

팀원의 개인 정보와 내부 문서는 포함하지 않습니다. 팀 공통 성과와 본인 역할, 설계 목표와 실제 검증 결과는 구분합니다. DB·WAS 복제와 운영 서비스 통합 검증은 진행 중 범위로 표시합니다.
